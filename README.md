# Rate Contract Dashboard

A single-file HTML dashboard for tracking procurement rate contracts (RCs): status (Active / Expiring ≤30 days / Expired / Upcoming), contract value, utilization, expiry outlook and vendor rate comparison (L1).

## Use
Open `rate-contract-dashboard.html` in any browser. No install or server needed.

- **+ Add RC** to enter contracts, or **Import CSV** to load from Excel (export first to get the column template).
- Data is saved in your browser's local storage. Use **Export CSV** to back it up or move it to another machine.
